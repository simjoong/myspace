GitHub Pages 배포 방법
1. github.com/new에서 새 저장소를 만드세요 (예: my-space)
2. 이 폴더의 모든 파일을 main 브랜치에 push
    git init && git add . && git commit -m "init" && git push
3. Settings → Pages → Source: main 브랜치, / (root) 선택 후 Save
4. https://[사용자명].github.io/[저장소명]으로 접속 가능
시장 리서치 자동화 설정
1. Anthropic API 키 발급: console.anthropic.com
2. GitHub 저장소 → Settings → Secrets and variables → Actions
3. New repository secret 클릭
4. Name: ANTHROPIC_API_KEY, Value: 발급받은 키 입력 후 저장
5. Actions 탭 → Market Research Auto-Update 워크플로우 활성화

설정 완료 후 매일 오전 9시(KST)에 자동으로 market-research.json이
업데이트되고, 페이지를 열면 최신 데이터가 표시됩니다.

수동 실행: Actions → Market Research Auto-Update → Run workflow
